- **3D Computer Vision & Perception:** Camera calibration, depth estimation, feature matching, and real-time obstacle detection.
- **Multi-Sensor Fusion:** Integrating vision, IMU, and inertial sensors for robust robot state tracking in complex environments.
- **Deep Learning Architectures:** Sequence modeling, transformers, self-supervised learning, and efficient representation learning.
